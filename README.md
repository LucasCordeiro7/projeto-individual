# Projeto ARCD

Plataforma web desenvolvida para a Associação de Judô ARCD São Bernardo do Campo, em contruibuição a todos os anos que me deram estrutura para treinar e suporte nos campeonatos. Destinada a quem tem interesse em conhecer ou já pratica Judô.

## Sobre o Projeto

O sistema permite que visitantes conheçam a associação e manifestem interesse através de um formulário de contato. Professores cadastrados têm acesso a uma dashboard para gerenciar atletas, visualizar gráficos e acompanhar interessados.

## Funcionalidades

- Página institucional com história, atividades e formulário de interesse
- Cadastro e login de professores com código de ativação por CREC
- Dashboard com KPIs, gráficos de distribuição por faixa e faixa etária
- Cadastro de atletas em tempo real
- Visualização de interessados pelo site

## Tecnologias Utilizadas

- **Front-end:** HTML, CSS, JavaScript
- **Back-end:** Node.js, Express
- **Banco de dados:** MySQL
